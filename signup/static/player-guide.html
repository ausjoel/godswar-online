GodsWar: how to start playing

Free private server · English · Mac and Windows · three steps

Step 1 · Make your account

Everything starts on the sign-up website:

https://YOUR-DOMAIN.example

Username4 to 16 lowercase letters and numbers. You type this name to log in to the game.
Password8 to 32 characters, no spaces. Use one you don't use anywhere else.
EmailUsed to look your account up if you need help. It is not verified yet.

One account can hold every character you make. If the site says new accounts are closed, ask the admin.

Step 2 · Mac

1
Download GodsWar-Launcher-mac.zip (6 MB) and unzip it.
2
On a Mac with an Apple chip (M1 or newer) install Rosetta once if you never have. Paste this into Terminal: 
softwareupdate --install-rosetta --agree-to-license
3
Double-click GodsWar Launcher. macOS refuses the first time. Click Done, open System Settings → Privacy & Security, scroll down and click Open Anyway. No button? Paste this into Terminal (change the path if the launcher is somewhere else): 
xattr -dr com.apple.quarantine ~/Downloads/"GodsWar Launcher.app"
4
The first start downloads the game (about 850 MB) and can take several minutes. A notification says what it is doing, and the game opens when it is ready. After that it only checks for updates.

Hold Option while the game opens to change window size or save your account.

Step 2 · Windows

1
Download GodsWar-Launcher-windows.exe (6 MB). Put it anywhere you like.
2
Double-click it. If Windows says it protected your PC, click More info, then Run anyway.
3
If Windows asks about the firewall, choose Allow.
4
The first start downloads the game (about 550 MB) into %LOCALAPPDATA%\GodsWar. A black window shows the progress and the game opens when it is ready. Next time it only checks for updates.
5
Closes straight away or mentions MSVCR80 or d3dx9? Install Microsoft's Visual C++ 2005 Redistributable (x86) and the DirectX End-User Runtime, then start it again.

The Windows version has not been test-played yet. If it fails, tell the admin what you saw.

Step 3 · Log in and play

Type the username and password from Step 1 on the login screen, pick a character slot and create your hero. Your skill bars and settings can be kept on the server: on Mac hold Option at launch, choose Accounts and save your account (the password goes in your Keychain).

If something goes wrong

Can't log inCheck the username is lowercase and the password is exactly what you set. Make sure you made the account on the website above.
Forgot password or usernameThere is no self-service reset yet. Message the admin with your username and the email you signed up with.
Game closes by itselfTell the admin roughly when it happened. On Mac the logs are in ~/Library/Logs/GodsWar; please send them.
Stuck in a wall or mapAsk a GM. They can move your character from the editor.
