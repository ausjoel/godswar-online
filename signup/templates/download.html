First time on a Mac

  1. Unzip GodsWar-Launcher-mac.zip and double-click GodsWar Launcher.
  2. macOS refuses the first time. Open System Settings → Privacy & Security, scroll down and click Open Anyway.
  3. On an Apple Silicon Mac, install Rosetta once if macOS asks.
  4. Wait for the first download. The game opens when it is ready.

Hold Option while the game opens to change the window size or save your account. Full steps: install help.

First time on Windows

  1. Run GodsWar-Launcher-windows.exe from anywhere. Always start the game from the launcher: it installs its own copy and keeps it up to date. A game zip you unzip yourself never gets updates.
  2. The launcher isn't code-signed, so SmartScreen may say "Windows protected your PC". Click More info, then Run anyway. Allow it through the firewall if asked.
  3. If your PC doesn't have Microsoft's Visual C++ 2005 runtime, the launcher installs it the first time. Windows shows one prompt ("Win32 Cabinet Self-Extractor", from Microsoft Corporation): click Yes.
  4. Wait for the first download. The game opens when it is ready.

After the first download, updates fetch only the files that changed, not the whole game.

Clicked No on that prompt, or Windows still says MSVCP80.dll is missing? Install the Visual C++ 2005 SP1 Redistributable (x86) from Microsoft's download page, then start the launcher again. If the game mentions d3dx9, install Microsoft's DirectX End-User Runtime. Full steps: install help.
